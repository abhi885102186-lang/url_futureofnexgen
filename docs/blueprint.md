# **App Name**: Nexus Assistant

## Core Features:

- User Authentication: Secure login page with email and password verification to protect user data.
- AI-Powered Voice Chat: Voice conversation interface, allowing users to communicate with the AI assistant through voice commands; mic access permission management included.
- Multi-Format File Analysis: AI tool supporting image, TXT, PDF and DOC file uploads for intelligent content analysis.
- Admin Content Management: Secured access for uploading PDF and Excel files, displaying them on a dedicated 'Font Section'.
- Member Management System: Add and display member details (name, mobile, email) with a well-structured display.
- Role-Based Access Control: Admin-controlled access rights (read, delete) within the settings panel.
- Chat History: Modern UI for chat history view and profile management, including appropriate data models and query structures in Cloud SQL database

## Style Guidelines:

- Primary color: Light teal (#A7DBD8) for a calming, accessible interface.
- Background color: Very light teal (#F0F8FF), almost white, providing a clean backdrop.
- Accent color: Pale rose (#E0BBE4) for interactive elements and highlights; not as saturated.
- Headline Font: 'Space Grotesk', sans-serif, used for headlines.
- Body Font: 'Inter', sans-serif, is the body font. 'Space Grotesk' for titles; this is appropriate because it features only short chunks of text.
- Code Font: 'Source Code Pro' for displaying code snippets and file data.
- Use modern, minimalist icons for all navigation and features.
- Ensure a clear, intuitive layout with a focus on easy navigation and content discoverability.
- Incorporate subtle, non-intrusive animations to enhance user experience (e.g., loading animations, transitions).
